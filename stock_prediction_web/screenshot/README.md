# 画面イメージの撮影(screenshot)

画面イメージ(PNG)を、本物の画面で撮る道具。

**画面に写る値は全て架空のもの**です。銘柄名は「サンプル○○」(例: サンプル精機、サンプル食品)、銘柄コードは 11110〜11780
(画面には4桁で 1111〜1178 と出る)。実在の会社・銘柄・人とは関係ありません。
画面イメージは GitHub に公開するポートフォリオにも使うので、架空の値に実在の会社名・人名・メールアドレス・PC のパスを入れません。

## 使い方(PowerShell で、stock_prediction_web のフォルダで)

```powershell
# 1. 画面をビルドする(画面のソースを直したとき)
cd frontend
npm run build
cd ..
# 2. 架空の値を入れて、全ての画面を撮る(約1分半)
.venv\Scripts\python -m screenshot.capture
```

| すること | コマンド |
| --- | --- |
| 全ての画面を撮る(架空の値も入れ直す) | `.venv\Scripts\python -m screenshot.capture` |
| 画面の番号を指定して撮る(例: 04 と 05) | `.venv\Scripts\python -m screenshot.capture 04 05` |
| 架空の値を入れ直さずに撮る | `.venv\Scripts\python -m screenshot.capture --skip-db` |
| 架空の値を入れるだけ(約25秒) | `.venv\Scripts\python -m screenshot.make_sample_db` |

出力先は `capture.py` の `OUTPUT_DIR` の `画面イメージ_NN_画面名_PC.png`(幅1366・倍率1)と `_スマホ.png`(幅390・倍率2)。
今あるファイルは上書きします。ページ全体を撮ります(04 銘柄詳細は業績のブロックまで)。

見込みの時間(2026-11-15 に利用者の PC で測った): 架空の値を入れる 約15〜25秒、全ての画面(26枚)を撮る 約1分。合わせて約1分半。

## 初めて使うとき

Playwright(プレイライト)と Chromium(クロミウム)を入れます(`requirements-dev.txt` に playwright があります)。

```powershell
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m playwright install chromium
```

## 何をしているか

1. `make_sample_db.py`: テスト用の DB(`stock_prediction_test`。API のテストと同じ)の全てのテーブルを作り直し、架空の値を入れる。
   - 基準の日(最新の予測日)は 2026-11-13(金)。乱数の種を固定しているので、毎回同じ値・同じ画面になる。
   - 68銘柄(プライム・スタンダード・グロース。33業種の全てに1銘柄以上)、株価日足は 2024-10-01〜2026-11-13、予測は直近245営業日。
   - 買い候補の順位はバッチの予測の関数、答え合わせと検証の集計はバッチの検証(`core.verify_core.verify`)で作る。
2. `capture.py`: 1. を行い、テスト用の DB につないだ API を **ポート 8081** でこのプロセスの中に起動して、Chromium で各画面を開き、
   操作して撮り、最後に API を止める。
   - 本番の DB(`stock_prediction`)には接続しない(`db_switch.py` が DB の名前を確かめて止める)。本番の API のサービス(8080)は止めない。
   - DB の切り替えは環境変数 `DB_NAME` で行う(バッチのコードと `.env` は変えない)。別の DB を使うときは環境変数 `TEST_DB_NAME`。
   - API の「今日」とブラウザーの時計は基準の日にそろえる。API のログは一時フォルダに出す(`logs` には書かない)。

## 画面ごとに再現している状態

| 番号 | 画面 | 状態 |
| --- | --- | --- |
| 01 | トップ | 初期表示 |
| 02 | 買い候補 | 「バッチ実行中の表示」を出し(実行中の行を一時的に入れて、撮った後に消す)、予測日(終了)のカレンダーを開く |
| 03 | 買い候補と実際の株価 | 上の日は60日後が未到来、下の日は全ての日数の答え合わせ済みになる期間 |
| 04 | 銘柄詳細 | チャートにマウスを置く(PC)。ボリンジャーバンドの表示は別の画像 |
| 05 | 保有銘柄 | 300株のうち100株を売る売却のダイアログ。売却済みのタブは別の画像 |
| 06・07・09・10・11 | 的中率・実行履歴・精度の比較・検討中銘柄・ランキング | 初期表示 |
| 08 | 銘柄検索 | 銘柄コード・銘柄名に「サンプル」を入れて検索(入力欄の見本の文字に実在の会社名があるため) |

画面を足したときは `capture.py` の `build_shots` に足します。
